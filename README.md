# Google Workspace Utils

Colección de funciones y scripts reutilizables para **Google Apps Script** y **Google Workspace**.

Este repositorio reúne utilidades para automatizar tareas, procesar y validar datos, y facilitar el trabajo con herramientas como Google Sheets, Gmail y Google Drive.

## 🚀 Uso

Cada utilidad incluye su código fuente y, cuando corresponde, documentación con instrucciones de instalación, sintaxis y ejemplos de uso.

Para utilizar una función personalizada en Google Sheets:

1. Abre la hoja de cálculo.
2. Ve a **Extensiones → Apps Script**.
3. Copia el código de la utilidad correspondiente.
4. Pégalo en el editor de Apps Script.
5. Guarda el proyecto.
6. Utiliza la función desde Google Sheets según su documentación.
